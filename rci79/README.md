# rci79 binaries

Прокси локального RCI `127.0.0.1:79` → SCGI `/var/run/ndm.scgi.socket` для KeeneticOS / Netcraze **5.1.9** (HTTP 403 без токена).

- **Upstream:** https://git.bobyrev.com/PCA/rci79  
- **Версия бинарников:** v1.0.0 (релизы upstream)  
- Установка через меню: **S → 4** / `menu rci79` / `installer_rci79.sh`

Файлы `rci79-aarch64`, `rci79-mipsel`, `rci79-mips` — сборки upstream, без изменений.
